# Claims Denial Prevention Checklist

Document Type: Revenue Cycle Checklist
Facility Scope: All facilities
Effective Date: 2026-01-20

## Pre-Claim Validation

1. Verify insurance eligibility at registration.
2. Confirm authorization number for prior-auth services.
3. Ensure diagnosis and procedure code pairing is valid.
4. Check modifier usage for bilateral or repeat procedures.

## Common Denial Drivers

- Missing documentation
- Authorization absent or expired
- Coding mismatch
- Late submission

## Operational Target

Keep initial denial rate below 8 percent for Medicare and below 10 percent for Commercial payers.
