# Sepsis Early Warning and Escalation Workflow

Document Type: Clinical Workflow
Facility Scope: All facilities
Effective Date: 2026-02-01

## Trigger Conditions

Escalation is required when any 2 or more are present:

- Temperature > 100.4 F or < 96.8 F
- Heart rate > 90 bpm
- Respiratory rate > 20 breaths per minute
- Suspected infection source

## First 60 Minutes Bundle

1. Notify provider and rapid response nurse.
2. Draw blood cultures before antibiotics.
3. Measure serum lactate.
4. Start broad-spectrum antibiotics within 1 hour.
5. Begin fluid resuscitation when hypotension or lactate >= 4 mmol/L.

## Escalation Rules

- Escalate to ICU consult if MAP < 65 after initial fluid bolus.
- Escalate if lactate remains elevated on repeat draw.
